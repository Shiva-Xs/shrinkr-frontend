Every link you shorten with Shrinkr comes with a QR code you can download and use anywhere. No account, no watermark, and no trial that quietly breaks the image later.

Why the short link makes a better code

A QR code encodes text, and the more text you give it the denser the grid becomes. Encoding a long URL full of campaign parameters produces a code with many small modules, and every one of them is a chance to fail when the code is printed small, lit badly, or scanned at an angle.

A six-character short link is a fraction of that input, so the resulting code has fewer, larger modules and far more tolerance for real-world scanning. This is the main practical reason to shorten before generating, rather than encoding the raw URL.

Printing and placing codes

  • Keep good contrast. Dark code on a light background scans best; inverting it is unreliable on some readers.
  • Leave the quiet zone. The empty margin around the code is part of the spec, and cropping it tight is a common cause of failed scans.
  • Mind the minimum size. As a rough rule, a code needs about a tenth of its scanning distance in width, so a code read from two metres wants to be around twenty centimetres across.
  • Test on a cheap phone. Older cameras are the real constraint, not new ones.

Knowing whether it worked

Because the code points at a short link, the click count on that link doubles as a scan count. Open the manage page for the link and the running total tells you how much the printed code is actually being used, which is usually the thing you wanted to know and cannot get from a raw URL.

Pairing a QR code with limits

The same link options apply. A QR code on a conference badge can point at a link with a click cap; a code in a time-limited promotion can point at a link with an expiry date, so scanning it after the promotion ends produces an expired page rather than a dead destination. A password works too, though it makes for a slower scan-and-read experience.

Questions

How do I turn a URL into a QR code?

Shorten the URL, then use the QR code button on the result. The code is generated on demand and can be downloaded as an image. There is no signup and no watermark.

Will the QR code stop working later?

The image never expires, because it is just an encoding of the short URL. It keeps working for as long as that short link does, so a link with no expiry date and no click cap has a QR code that works indefinitely.

Can I change where the QR code points after printing it?

Not currently. The destination of an existing link is fixed, so a printed code cannot be repointed. Expiry, click limit and password are the settings that remain editable from the manage page.

Why encode a short link instead of the original URL?

Shorter input means fewer modules in the code, which makes it visually simpler and far more tolerant of bad lighting, low print resolution and being scanned at an angle. Encoding a long URL directly produces a dense code that fails more often in practice.
