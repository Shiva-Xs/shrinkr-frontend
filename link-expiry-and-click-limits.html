Links that expire, or stop after N clicks

Not every link should live forever. Shrinkr can retire one on a schedule, either at a date and time you pick, or once it has been clicked a set number of times.

Both limits are set with the --expiry and --max-clicks options when you create the link, and both are optional. A link with neither simply keeps working.

Expiry by date

Pick an instant and the link redirects normally right up to it, then serves an expired page afterwards. This is enforced at the data layer rather than by a cleanup job, so there is no window where a link outlives its deadline: the cached copy of an expiring link has its cache lifetime capped at the expiry instant, which means the cache itself cannot serve a stale redirect past the deadline.

Expiry by click count

A maximum click count retires the link once it has been used that many times. Set it to one and you have effectively a single-use link: the first visitor gets through and everyone after sees the expired page.

Click counts are buffered server-side and flushed periodically rather than written on every hit, which is what keeps redirects fast. In practice the cap is enforced promptly, but it is a limit for managing distribution rather than an exact-count guarantee for a high-volume link.

Where this is useful

  • Handing off a file or invite that should not stay live in a chat log forever.
  • Time-limited campaigns where the destination will be taken down anyway and you would rather serve an expired page than a 404.
  • Beta or preview access capped to a known number of visitors.
  • Anything you would otherwise have to remember to delete. The link cleans up after itself.

Combining limits

Expiry, click limit and password are independent. Setting all three gives you a link that needs a secret, dies on a date, and stops early if it gets used more than you expected. Whichever condition is hit first ends it.

Everything remains editable from the manage page as long as you hold the manage token from creation time, so a deadline can be extended or a cap lifted without minting a new link.

Questions

How do I make a link that expires?

Set an expiry date and time using the expiry option when you shorten the URL. After that instant the link stops redirecting and serves an expired page instead.

Can I make a single-use link?

Set the maximum click count to one. The first visitor is redirected and every visitor after that gets the expired page. Any number works, so a cap of five behaves the same way after the fifth click.

Does an expired link get reused or deleted?

The slug is retired rather than recycled, so an expired short URL never silently starts pointing somewhere new. You can delete the link outright from the manage page if you prefer.

Can I change the expiry or click limit after creating the link?

Yes. Both are editable from the manage page using the manage token issued at creation time. You can extend a deadline, tighten a click cap, or remove either limit.
